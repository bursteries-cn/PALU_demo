# 逐样本永久停止遗忘：seed 103、104、105

本轮仅运行遗忘阶段，学习率由 `1e-5` 降到 `5e-6`，目标仍为 `F + 2 common-KL`。每个种子从原始 Full 模型独立开始，依次使用同一组四卡；不接续上一轮停止模型，不执行保留阶段。

## 停止规则

每个 epoch 结束后的第一个完整更新步，固定模型计算全部 200 条 Forget 的逐样本 F 和 common-KL。每条样本的 F 为其敏感 token 损失平均值。当该值首次严格小于 `0.5`，从下一更新起永久关闭这条样本的 F 项；common-KL 继续生效。`0.4` 仅用于记录是否跌破下界，不触发反向补偿或重新启用。

- F/R 样本及配对保持冻结；停止某条 F 后不重采样或缩小 batch。
- F 的归一化分母仍为原完整更新步的敏感 token 总数，包含已停止样本的 token；只屏蔽相应分子，避免把额外权重转移给剩余样本。
- 没有敏感 token 的样本不参与停止判定，也不算作阈值命中；其 common-KL 仍保留。现有固定 F200 中有 4 条此类样本，实际以本轮冻结记录为准。
- 所有有敏感 token 的样本都已停用时结束；否则最多 63 次更新（2,016 对曝光，10.08 个曝光 epoch）。降低学习率后可能耗尽预算，此时明确记录尚未停止的样本，不自动延长训练。
- 模型参数共享，停用样本的损失仍可能变化，甚至离开 `[0.4, 0.5)`；继续评估和记录漂移，但不重新启用。该规则不保证样本最终落在区间内。
- 停止决策只看本轮模型的逐样本 F，不使用 Retain 模型、TR 或 FQ 反馈。

其他配置沿用 seed103：四卡、每卡 batch 1、累积 8、有效 batch 32、整步 token 归一化、常数学习率且无 warmup。seed103 重放历史配对；seed104、105 使用各自冻结采样序列。零权重 R 只做无梯度前向记录损失，使用此前已通过 GPU 等价性检验的可选优化。

## 启动

在服务器 PALU 仓库中，先查看冻结计划（不会加载模型或开始训练）：

```bash
MODE=dry-run bash scripts/palu/run_sample_forget_threshold.sh
```

正式启动：

```bash
bash scripts/palu/run_sample_forget_threshold.sh
```

指定 GPU 或 Python 时：

```bash
FOUR_GPUS=0,1,2,3 PYTHON_BIN=.venv/bin/python \
  bash scripts/palu/run_sample_forget_threshold.sh
```

默认结果目录为 `artifacts/sample_forget_threshold/<时间戳>/seed_<种子>`。默认源实验为 `artifacts/token_equal_seed103/20261017_192348`；可用 `SOURCE_STUDY` 指向相同历史源实验。新目录不能已存在。三个种子顺序运行，避免争用同一组 GPU。

每轮 F200 探针保存逐样本损失和停用状态；FQ/TR 初始、每 2 个曝光 epoch 和结束时评估，MU 仅结束时评估一次。在线完整更新仍记录 F、R、common-KL。评估后删除已验证的中间模型，保留最终模型、原生优化器/RNG 状态和完整结果。每个种子准备时检查至少 160 GiB 空闲；最终模型加 Adam 重启状态仍约 100–120 GiB/种子，三个种子均保留。

控制参数只在准备时写入冻结计划。已经准备的实验禁止通过训练或分析命令更改学习率、种子和停止方式。旧 `run_forget_until_threshold.sh` 默认继续使用全局停止规则、`1e-5`、四个旧种子；本轮请使用新入口。

本轮同时改变学习率和停止粒度，结果适合判断组合方案的行为，不能单独归因于其中一项。
